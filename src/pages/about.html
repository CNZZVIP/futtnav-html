关于我们

了解福天天导航 —— 我们相信，一个好的导航站应该安全、实用、高效。

我们的故事

福天天导航最初只是一个简单的静态网址收藏页，方便自己快速找到常用的网站。随着不断的整理与迭代，它逐渐成长为一个收录数百个精选网站的导航站，并在反复打磨中沉淀出一套简洁、清爽、好用的交互体验。

我们坚持三个原则：

  • 安全 —— 人工筛选站点，优先收录官方、权威、口碑良好的网站；
  • 实用 —— 只收录真正有价值的网站，分类清晰、检索高效；
  • 高效 —— 页面轻量、秒开无广告干扰，让你一键直达目标。

开源版

你现在看到的是福天天导航的 开源版：一个无后台、纯 HTML 的静态导航站，代码完全开源（MIT 协议），在 Gitee / GitHub / CNB 三端仓库同步维护，可自由部署到任何静态托管平台。

为什么要做开源版？
让开发者可以快速了解导航站的核心实现（纯 HTML + CSS + JS，零依赖），也可以直接拿来当作个人起始页 / 团队导航页使用。

开源版功能精简；功能完整的正式版收录 2000+ 精选网站，支持在线后台管理、AI 智能助手、天气、多主题等能力，欢迎体验：

https://hao.futt.cn

完全开源 · 随处可部署

本项目是纯静态站点：没有后端、没有数据库、不需要任何运行时（Node / PHP / Java 均不需要）。构建产物只有一组静态文件，任何能托管静态文件的空间都能直接运行，例如：

  • 云存储 / 对象存储：腾讯云 COS、阿里云 OSS、华为云 OBS、七牛云 Kodo、又拍云、火山引擎 TOS、AWS S3、Cloudflare R2、MinIO（自建）；
  • 静态托管：Vercel、Netlify、Cloudflare Pages、GitHub Pages、Gitee Pages、腾讯云 EdgeOne Pages；
  • 服务器 / NAS：任意 Nginx / Apache 虚拟主机，群晖 / 飞牛等 NAS 的 Web 根目录。

部署只需两步：
① 本地执行 npm run build 生成 dist/ 构建产物；
② 把 dist/ 目录下的全部文件（index.html、help.html、about.html、privacy.html、favicon.svg、assets/ 等）上传到存储空间根目录，开启「静态网站托管」即可访问。
不需要源码、不需要 node_modules、不需要任何配置文件，完全独立运行。

更详细的部署教程（含各平台操作步骤）见项目 README 文档。

项目特点

纯 HTML，零依赖
原生 HTML / CSS / JavaScript，无框架、无构建工具依赖，双击即可打开。
多引擎搜索
内置百度、必应、360、谷歌四款搜索引擎，一键切换，移动端同样可用。
深色 / 浅色主题
跟随系统或手动切换，支持记忆偏好，夜晚浏览更舒适。
一键部署
内置 EdgeOne Makers 配置，推送到 Git 仓库即可自动构建上线。
